# プロジェクト概要

INK on HEXは、ヘックス盤面に3色のインクを垂らし、限られた手数で課題色を作るブラウザのパズルゲーム。ゲーム本体（ミッション・アトリエ・コレクション）と、ミッションを作る外部ツールのステージメーカーで構成する。
