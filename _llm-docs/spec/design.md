# デザイン仕様

## 寸法

- 8pxを単位にする。余白と部品の大きさは8の倍数（8・16・24・32・48・56・64）で取る
- 同じまとまりの中で要素どうしを詰めるときだけ、半分の4pxを使う（アイコンと数字の間、セルどうしの間）
- 8の倍数でない値は、線の太さと、文字や図形の見た目の位置合わせ（1〜3px）に限る

## 文字

- フォントはJetBrains Monoで、数字は等幅にする
- 本文は16px・行の高さ24pxを基準にする
- 大きさは役割で決める。小さな印（CLEAR、点数の印の数字）は12px、本文とカウントは16px、コレクションの色名は18px、画面の見出しは24px、到達の結果（最終スコア）は32px、タイトルは40px。値の正本は`src/styles/index.scss`のCSS変数（`--font-size-*`）とする
- 文字は大文字の高さで切り詰め、アイコンやヘックスと高さをそろえる

## 色

- 画面の部品は無彩色だけで作り、色はインク（ゲームの中身）にだけ使う
- 黒は、結果や到達を示す要素（CLEAR、最終スコア、トロフィー）に使う
- 灰は、経過や補助の情報（セル数、点数の行）に使う
- 押せない状態は、不透明度を0.3にして示す（`--opacity-disabled`）

値の正本は`src/styles/index.scss`のCSS変数とする。

| 用途             | CSS変数          | 値        |
| ---------------- | ---------------- | --------- |
| 背景             | `--bg-basic`     | `#ebebeb` |
| セル             | `--bg-cell`      | `#fff`    |
| 黒（文字）       | `--txt-basic`    | `#1c1c1c` |
| 灰（補助の情報） | `--txt-muted`    | `#8a8a8a` |
| 線               | `--border-basic` | `#d0d0d0` |

## 形

- ヘックスを共通の形にする（セル、課題色、点数の印、ホームのタイル、一覧のサムネイル）
- 記号は絵文字や文字で代用せず、アイコンとして描く（×、戻る、リトライ、undo、redo、トロフィー、しずく、選択欄を開く印）
- 文字として書く記号は、式の等号（=）と、まだ作っていない色を伏せる「?」だけにする

## 動き

- 段階を追って見せるときは、0.3秒の間を置く
- 部品を消すときは0.24秒で消し、現れるときより短くする
- 複数の要素は、0.05秒ずつずらして出す
- UIの部品の登場は、行き過ぎてから落ち着かせる（CLEARの文字は跳ねてから着地、レシピの点は大きくなってから戻る）
- 画面や状態が変わっても残る部品は、消して描き直さない（戻るボタンは常駐、フッターの入れ替えはクロスフェード、リトライ時のカウントは巻き戻す）

## スコア領域（ミッション）

- 1行目: 課題色のヘックス（56px）と `CLEAR` の表示位置、その下に `× 課題色のセル数`（プレイ中にリアルタイムでカウントアップ）。
  - 課題色が2色のときは、ヘックスを横にずらして重ねて置く。
  - CLEARしている間は、課題色のヘックスも盤面の課題色セルと同じくときどき光る（glint）。
- 1〜6点の各行: `[点数の印] × NN = NNN`。NNは0詰め2桁のセル数。NNNはプレイ中は伏せ字。
- 終了すると、NNNを計算値にカウントアップで置き換え、続けて `× 単純合計 = 最終スコア`（最終スコアは黒字32px）を出す。
- リトライ時、課題色のセル数は0まで、各行の値はNNNまで戻す。`× 単純合計 = 最終スコア`の部分はフェードアウトで消す。

## PCレイアウト

- 判定: 幅900px以上かつ横長（`isWide()`、SCSSは`mq-wide`）。
- プレイ画面: 盤面は全面、スコア領域は左カラム（360px）、手数とパレットは右下、undo / redoはパレットの左隣にアイコンのまま。戻る・リトライは縦並びでラベル付き。1〜6の行は1列。
- ミッション一覧・コレクション: 左カラム（240px）にタイトルと戻る、右に一覧。コレクションは複数列。
- スクロールのある画面は右端と上部に余白を広めに取る。

## 演出の時間

時間とイージングの正本は`src/styles/index.scss`のCSS変数とする。

| 内容                                               | CSS変数               |
| -------------------------------------------------- | --------------------- |
| 標準のイージング                                   | `--ease-standard`     |
| 複数の要素を順に出すずらし                         | `--duration-stagger`  |
| 広がりが1段進む間隔                                | `--duration-ring`     |
| 消す（フッター右の入れ替え、リトライ時に消す部分） | `--duration-fade-out` |
| 盤面の色の切り替え                                 | `--duration-color`    |
| セルの膨らみ                                       | `--duration-pulse`    |
| 画面の中身が現れる                                 | `--duration-fade-in`  |
| タイルの登場                                       | `--duration-spawn`    |
| 手数の列・点数表の出入り                           | `--duration-move`     |
| 盤面の寄り引き                                     | `--duration-zoom`     |
| カウントアップ                                     | `--duration-count`    |

段階のあいだの間は`src/features/play/useScorePanel.ts`、CLEAR・トロフィーの跳ね方は`src/utils/hop.ts`、点やボタンのはずみ方は`src/utils/pop.ts`の定数とする。
