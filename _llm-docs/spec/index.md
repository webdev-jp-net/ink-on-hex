# INK on HEX 仕様

数値の正本は`src/`のコードの定数とする。

## 下層の仕様

- [技術仕様](./tech_structure.md) - 技術スタック・ディレクトリ・構成・描画・アニメーション・テスト
- [デザイン仕様](./design.md) - 色・文字・寸法の決まり、スコア領域、演出のタイミング、PCレイアウト

## ルール（`src/game/core.ts`）

- 盤面はヘックス（六角形）のセルの集まり。座標はaxial座標 `q,r`、セルのキーは `"q,r"`。
- インクはCyan / Magenta / Yellowの3色（`INK_LIST`）。
- 1セルのインク量の上限は6（`MAX`）。セルの中身は3色それぞれの量の配列（例: `[4,2,0]`）。
- **垂らす**: 選んだセルに選んだインクを垂らすと、距離0のセルに6、距離1に5 … 距離5に1が加わる。
  - 各セルには上限6までしか入らない（あふれた分は捨てる）。
  - 盤面の欠け（抜いたセル）は越えない。広がりは盤面上をたどった距離。
  - 合計がすでに6のセルには垂らせない。
- **色名**（`colorNameOf`）: 合計が6のセルだけ色名がつく。
  - 1色だけ: そのインク名。
  - 2色: `PAIR_COLOR_NAME_LIST`の両端を除く5段階（例: Cyan→Azure→Cobalt→Blue→Purple→Violet→Magentaのうち、Azure〜Violet）。
  - 3色: 等量ならBlack、それ以外は共通分を引いた残りで `Dark ○○`。
  - 混色名は全25種（`MIXED`）。

## ミッション

- ミッションは`MISSION_LIST`に定義する。各ミッションは盤面半径`radius`、手数 `moveCount`、使えるインク `inkList`、課題色 `targetColor`、抜いたセル `removed` を持つ。
- 課題色は1色または2色。
- **終了**: 手数を使い切った時点、または盤面のすべてのセルが6で埋まった時点。
- **CLEAR条件**: 課題色それぞれが盤面に1セル以上あること（2色なら両方とも1以上）。
- **スコア**（終了時に計算）:
  - 単純合計 = 各セルのインク量の合計（1〜6点のセル数×点数の総和）。
  - 最終スコア = 課題色のセル数（2色の場合は2色の合計）× 単純合計。CLEARしていなければ0。
- **ベストスコア**: ミッションごとに最高スコアとその時の垂らし方（セルとインクの列）を保存。0はベスト扱いしない。
  - 保存はスコア計算の演出を始める時点で行う（演出の途中で画面を離れても記録は残る）。トロフィーの表示は演出の最後。
  - ベストの再生では記録しない。
  - ミッションを開いて1手も垂らしていない状態では、フッター右にトロフィーのボタンが出て、ベストの盤面をクリア時と同じ演出で再生する。再生中の盤面タップは無視する。

## 画面

- **ホーム**: ミッション / アトリエ / コレクション への入口。背景はヘックスのタイル（前の画面から引き継いだタイル以外は、ランダムに欠ける。1枚抜け落ちるのと、別の欠けに1枚戻るのを、交互にくり返す）。
- **ミッション一覧**: 各ミッションの盤面サムネイル。
- **ミッションのプレイ画面**: 上部にスコア領域、中央に盤面、下部に手数とパレット、フッターに戻る・リトライ（またはトロフィー）。
- **アトリエ**: 半径6の盤面に手数制限なしで垂らせる。undo / redoあり。
- **コレクション**: 色の一覧と、作った回数。
  - 一覧は2色の段階順（Cyan→…→Magenta→…→Yellow→…→Spring Green）の後に、3色の混色が続く。
  - Cyan / Magenta / Yellowは最初から表示。混色25種は、作るまで「?」で伏せる。
  - 作った回数は、垂らした結果セルがその色に変わるたびに1増える。
  - 記録するのは、ミッションをクリアしたプレイだけ（終了時にまとめて記録）。クリアできなかったプレイ、途中で抜けたプレイ、アトリエ、ベストの再生では記録しない。
- **戻る**: ミッションのプレイ画面からはミッション一覧へ、アトリエ・一覧画面からはホームへ。

## 保存（localStorage）

| キー                      | 内容                                   |
| ------------------------- | -------------------------------------- |
| `inkOnHex.collectionList` | 作った色                               |
| `inkOnHex.madeCount`      | 色ごとの作った回数                     |
| `inkOnHex.bestList`       | ミッションごとのベストスコアと垂らし方 |
| `inkOnHex.maker`          | ステージメーカーで編集中のステージ     |

保存はブラウザの配信元（オリジン）ごとに分かれるため、公開URLが変わると記録は引き継がれない。

## ステージメーカー

ミッションを作る外部ツールで、ゲーム内の機能ではない。

- 編集: セルのオン/オフ、使うインク、手数、課題色（最大2色）。
- プレイ: その盤面を試しに遊べる。
- Check: ランダムに垂らす試行を20000回行い、クリア率・最高スコア・クリア時の平均スコアを出す。
- 読み込み: 既存ミッションを選んで編集できる。
- 書き出し: `MISSION_LIST`にそのまま貼れる1件分の定義（抜いたセルは`removed: cellSet('q,r;…')`）。
- ミッションを足すときは、この書き出しをそのまま使う。
